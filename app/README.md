# ChemCalc

Калькулятор химии и напитков для SS14 (Arcane).

Сайт: https://kinar7.github.io/ChemCalc/
Локально: открыть `ChemCalc.html` в корне.

Рецепты каждый день сами собираются из ArcaneSS14/arcane (GitHub Actions).
Локальная версия при открытии подтягивает свежие данные с сайта, без интернета работает на тех, что лежат рядом.

`Обновить данные.bat` скачивает свежий data.js с сайта, чтобы работало и без интернета.

Собрать из своей репы: `python build_data.py` (берёт ../../Arcane, нужен `pip install pyyaml`).
Другая репа: `python build_data.py "путь/к/репе"`.
